# Tally Server

Tally: highlighting and its language server.

This extension gives the files of the Tally language (`tally`) the Tally language server. The language itself, and its colouring, come from another extension.

Generated by nexus v2.3.0 from tally.grammar.

## Settings

| Setting | Meaning |
|---|---|
| `tally.server.path` | the language server: a path, or a name on `PATH`, read from user settings only; empty means the extension's `bin/tally-lsp`, else `tally-lsp` on `PATH` |
| `tally.server.root` | the file the program starts from, which the server analyzes, relative to the first workspace folder; empty means each file's own program |
| `tally.server.modules` | the file of each module name an import names (`{"std": "/path/to/std.zig"}`), relative to the first workspace folder; an import of another name names a file relative to the importing file |
| `tally.server.check` | a command that checks the program when a file opens or is saved, as its words (`${file}` the file, `${root}` the root), read from user settings only and run only in a trusted workspace; its `PATH:LINE:COL: error: MESSAGE` lines, and `warning:` and `note:` lines, are diagnostics |
| `tally.server.checkTimeout` | the milliseconds a check may run before it is stopped; 60000 by default |
| `tally.features` | the features the server serves, of those it has; all by default; beside another language server, the features it lacks, such as `["semanticTokens", "folding", "selection", "check"]` |

## Building and packaging

The language server is a Zig project beside this directory:
`zig build --prefix ../vscode` in `server/` puts `bin/tally-lsp`
in the extension. Then, in this directory:

```bash
npm install
npx @vscode/vsce package --skip-license
```

`--skip-license` packages the extension without a `LICENSE` file in
this directory.
