# Tally (Nexus)

Tally: highlighting and its language server.

This extension gives VS Code the Tally language: its files (`.tally`), their colouring and the Tally language server.

Generated by nexus v2.3.0 from tally.grammar.

## Settings

| Setting | Meaning |
|---|---|
| `nexus-tally.server.path` | the language server: a path, or a name on `PATH`, read from user settings only; empty means the extension's `bin/tally-lsp`, else `tally-lsp` on `PATH` |
| `nexus-tally.server.root` | the file the program starts from, which the server analyzes, relative to the first workspace folder; empty means each file's own program |
| `nexus-tally.server.modules` | the file of each module name an import names (`{"std": "/path/to/std.zig"}`), relative to the first workspace folder; an import of another name names a file relative to the importing file |
| `nexus-tally.server.check` | a command that checks the program when a file opens or is saved, as its words (`${file}` the file, `${root}` the root), read from user settings only and run only in a trusted workspace; its `PATH:LINE:COL: error: MESSAGE` lines, and `warning:` and `note:` lines, are diagnostics |
| `nexus-tally.server.checkTimeout` | the milliseconds a check may run before it is stopped; 60000 by default |
| `nexus-tally.features` | the features the server serves, of those it has; all by default |

## Building and packaging

The language server is a Zig project beside this directory:
`zig build --prefix ../vscode` in `server/` puts `bin/tally-lsp`
in the extension. Then, in this directory:

```bash
npm install --ignore-scripts
npx @vscode/vsce package --skip-license --allow-missing-repository
```

`npm install` installs the client's library and esbuild, which needs
none of its install scripts; `vsce package` first bundles the client
into `dist/extension.js` (`npm run vscode:prepublish`), the one file
of JavaScript the package holds.
`--skip-license` packages the extension without a `LICENSE` file in
this directory; `--allow-missing-repository`, without a
`repository` in `identity.json`.
